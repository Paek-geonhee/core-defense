# 중앙 방어전 / Core Defense

Processing과 웹으로 구현한 생존형 타워 디펜스입니다.

## 실행

- **웹:** [게임 시작](https://paek-geonhee.github.io/core-defense/) 또는 저장소의 `index.html`을 브라우저로 엽니다. 화면을 누른 채 조준하면 발사합니다.
- **Processing:** `TowerDefense.pde`를 내려받아 Processing 4에서 엽니다. Processing이 같은 이름의 폴더를 만들도록 안내하면 수락하세요. Enter 또는 Space로 시작하고, 마우스를 누른 채 조준합니다. 게임 오버 후 R로 재시작하거나 Q로 종료합니다.

## 규칙

- 체력은 5로 시작하며 최대 5입니다. 적이 타워에 닿으면 체력이 1 감소합니다.
- 적은 탄환 한 발에 처치되고 10점을 얻습니다. 시간이 지날수록 적이 빠르고 많이 등장합니다.
- 적 처치 시 18% 확률로 아이템이 떨어집니다. 탄환으로 맞히면 획득하고 12초 후 사라집니다. 초록은 체력 1 회복, 주황은 주변 적 처치(각 10점), 노랑은 100점입니다. 범위 아이템으로 처치한 적은 아이템을 떨어뜨리지 않습니다.
- 체력이 0이 되면 최종 점수와 생존 시간이 표시됩니다.
