# 중앙 방어전 / Core Defense

같은 규칙을 Processing과 웹으로 각각 구현한 생존형 타워 디펜스입니다.

## 실행

- **웹:** `web/index.html`을 최신 브라우저에서 엽니다. 설치나 서버가 필요하지 않습니다. 마우스 또는 터치를 누른 채 조준합니다. 모바일에서는 화면 비율에 맞게 표시됩니다.
- **Processing:** Processing 4에서 `processing/TowerDefense/TowerDefense.pde`를 열고 실행합니다. 시작 화면에서 Enter 또는 Space를 누릅니다. 마우스를 누른 채 조준하며, 게임 오버 후 R로 재시작하거나 Q로 프로그램을 종료합니다.

## 규칙

- 타워 체력은 5로 시작하며 최대 5입니다. 적이 타워에 닿으면 적이 사라지고 체력이 1 감소합니다.
- 누르고 있는 방향으로 자동 발사하며, 적은 탄환 한 발에 처치되고 10점을 얻습니다. 시간이 지날수록 적의 출현 주기가 짧아지고 속도가 빨라집니다.
- 적 처치 시 18% 확률로 아이템이 떨어집니다. 탄환으로 맞혀 획득하며 12초 후 사라집니다. 초록은 체력 1 회복, 주황은 아이템 주변 적 처치(각 10점), 노랑은 100점입니다. 범위 아이템으로 처치한 적은 아이템을 추가로 떨어뜨리지 않습니다.
- 체력이 0이 되면 최종 점수와 생존 시간이 표시됩니다. 웹의 게임 종료는 시작 대기 화면으로 돌아갑니다.

외부 라이브러리나 이미지 에셋은 사용하지 않습니다.
